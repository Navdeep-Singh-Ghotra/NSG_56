Problem: Dynamic connectivity (e.g., network connections, pixels in a photo).

API: Define the key operations: find(p), union(p, q), count() .

Algorithms & Complexity: Compare the three primary implementations:

Quick-Find: find is O(1), union is O(N). Note the id[] array stores component identifiers .

Quick-Union: union is O(N), find is O(N) (worst-case). Represent components as trees where id[i] is the parent of i.

Weighted Quick-Union: Tracks the size of each tree to avoid tall trees. union and find are O(log N). This is the preferred approach before path compression .

Improvements: Path compression makes find nearly O(1). Together with weighting, the amortized cost is almost constant (the inverse Ackermann function) .
